# Onboarding guide

## Getting access
Ask your team lead to add you to the engineering group. Access to the AWS account is granted through an individual login, and production access is requested separately.

## Local setup
Install Terraform, Python and Git. Clone the repository, create a virtual environment, and install the pinned requirements. Run the chunker and the tests before opening your first pull request.

## First deployment
Open a pull request and wait for the checks to pass. Merging deploys to the dev environment. Production deployments are started manually.
